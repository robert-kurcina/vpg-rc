# LLM provenance and historical development record

This directory contains previous AI-authored implementation notes, release notes and
cleanup audits. These files are retained for traceability, not authoritative current
configuration or executable dependencies. Revisions can contradict each other; current
`PLAN.md`, executable source, original user SVGs and rulebooks are the relevant sources.

- `llm/release-history/`: archived historical version notes (v282–v316)
- `llm/historical-audits/`: prior cleanup/audit manifests

Earlier version ZIPs and screenshots were not embedded; they are redundant with the current
distribution, and may be retained separately in the conversation history.
