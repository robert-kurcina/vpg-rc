# v314 — Visible source-anchored Coast wavelets

Leningrad `path482` remains the sole Coast geometry source. The visual wavelet fringe now extends slightly landward from the fixed path, rather than seaward onto an indistinguishable teal Sea background. It uses five samples per authored path segment and deterministic two-frequency variation. No independent coastline, sea polygon, or coast side is invented. Other maps use their existing rendering paths.
