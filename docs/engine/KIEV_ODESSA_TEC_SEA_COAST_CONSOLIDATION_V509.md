# Checkpoint 275 / v509 — Consolidated Sea / Coast TEC entry

The Objective: Kiev (Odessa supplement) Terrain Effects Chart now displays
13 rows, with **Sea / Coast** as one entry. The separate Coast row is removed.
The remaining Sea specimen is still an authentic isolated Sea hex rendered by
the shared game engine, and the combined row explains that Coast denotes the
land–Sea shoreline rather than an independent terrain cost or combat modifier.

The **Lake** row remains separate. **Romania** and **Bessarabia** remain the
final two chart rows. Nothing in the source maps, movement eligibility, coast
hexside barriers, CRT, game engine, or other scenario rules was changed.

The original v507 and v508 Coast specimen references remain historical
provenance; the active chart no longer references a separate Coast sample.
