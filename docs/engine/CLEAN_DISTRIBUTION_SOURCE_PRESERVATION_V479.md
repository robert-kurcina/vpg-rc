# Checkpoint 245 / v479 — lean checkpoint distribution, source preserved

## Scope

Checkpoint 244 included many historical screenshots and map overlays generated by prior test runs. They are not required to run the shared renderer, browser games, Kiev territory or movement workbenches, or source-pinned tests. Keeping all old screenshots in every successive full checkpoint obscures the distinction between **authoritative source assets** and **ephemeral screenshots**.

Checkpoint 245 creates a **clean, source-complete** distribution. The archive builder omits obsolete root export logs and historical generated visual snapshots, while retaining the original rule PDFs, supplied/source map SVGs and scans, authored scenario configs, all five approved runtime map SVG/PNG exports, every original counter sheet, all historical source ledgers and numeric test/audit JSON files, scripts, tests, game runtime and UX code, and seven named visual fixtures/recent Kiev browser renders. It does not modify the shared game engine or promote Kiev's provisional source graph.

## Source and visual-policy rules

- Run `python3 scripts/build-clean-checkpoint-v479.py --output PATH_TO_ZIP --baseline PATH_TO_CHECKPOINT_244_ZIP` to build and compare against the prior full package. The output must be outside the source tree.
- The complete per-path, per-hash removal index is `provenance/package-pruning-v479.json`. This is a reversible **packaging exclusion**, not deletion from the source working tree. Checkpoint 244 remains a full-source artifact for recovery of any omitted historical screenshots.
- Source-dependent visual fixtures for Leningrad original scan and Arduous river-candidate tests remain included. The current Kiev setup, territory-review, citations, and edge-review Chromium screenshots remain, together with the v479 actual-engine five-map viewer screenshot. The actual shared-engine map SVGs and PNGs are never excluded.
- Older screenshots may be regenerated by their `tests/*browser*.py` scripts or renderer scripts. Do not treat their absence as missing authored source. Documentation referencing omitted past screenshots must consult the old full checkpoint or regenerate evidence. Source-rule adjudication does not depend on their copied pixels.
- The builder has a fail-closed source-fingerprint check against the supplied baseline full checkpoint. It permits edits to only the three tracking documents among original v478 files; new builder, test, report, and provenance index are additive.
- `PACKAGE_MANIFEST.json` lists precisely the cleaned ZIP's files, with SHA-256 and byte sizes. `tests/clean-distribution-v479.py ZIP` audits ZIP paths, file hashes, source/runtime/export presence, pruning behavior, and Kiev's still-closed gameplay gates.

## Remaining limitations

**No playability advancement is claimed from packaging alone.** Kiev still lacks a complete adjudicated Romanian-territory mask for §10.8 and approved movement-graph source authorization; only the candidate diagnostic graph may be tested. Kiev–Odessa remains behind Kiev. The historical source screenshots deleted from *this distribution only* are not part of an independent historical review sign-off, and the minimized distribution deliberately does not include them.
