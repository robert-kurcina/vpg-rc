# Checkpoint 244 / v478 — Kiev movement source-edge review workbench

## Purpose

Checkpoint 243 established evidence-attributed manual review for the missing Romanian §10.8 national territory. A separate source-authorization blocker is the Kiev candidate movement graph: all 165 source-registered hexes and 442 physical connections are executable in isolated tests, but the live graph registry remains `provisional`. This checkpoint makes the **existing** source-reviewed candidate graph inspectable edge-by-edge against the actual engine-rendered Kiev map without promoting it to historical gameplay.

The original source vector is `maps/source/user-svg/kiev-odessa-main.svg` (SHA-256 `2b15c3a92a282a7efc27d54bcd8994470f0fce8ee5417d5d734969fcd2c4ab7e`). The unchanged edge ledger is `maps/movement-configs/source-reviewed-edge-ledgers.json`, bound to the v435 source graph policy. The standalone Kiev renderer's unchanged map is `exports/kiev.svg`.

## Implementation

- `tools/build-kiev-movement-edge-review-v478.js` calls the same original `core/source_reviewed_movement_graph.js` used in the prior 2,949-assertion Kiev geometry qualification. It checks original SVG SHA, exact candidate edge-ledger SHA, original v435 policy, and explicitly rejects production `MapGraph.build(kiev)`. It writes only a source-pinned **diagnostic audit**: `rules/audit/kiev-movement-edge-review-v478.json`.
- Every candidate hexside is given a deterministic ID `hostCell:hostCell`, source feature flags, and endpoints derived from the actual shared renderer's `gridRadii`/`hexPoints` geometry. The endpoints are the original **shared physical sides**, not interpolated lines from screenshots. The generated audit has its own SHA-256, pinned independently in the diagnostic page's config. The 165 source hexes, 442 sides, **93 railway**, **72 ordinary-river**, and **10 Major River** connections are unchanged.
- `tools/movement-review/index.html` and `app.js` display `exports/kiev.svg` unchanged underneath an independent, selectable diagnostic SVG **overlay**. They do not generate alternative terrain, map counter art, or a second map renderer. The overlay supports separate river/rail filter predicates even where features overlap, candidate inspection, review/dispute/clear, original printed-map comparison, source provenance, review count, review navigation with Major River priority, keyboard/touch interaction, and checksum-protected draft export/import.
- The draft envelope names the exact source audit checksum, and can be restored only against the same source-pinned candidate. A wrong source, invalid edge ID, bad status, or tampered checksum is rejected atomically. **All manual review states, including 442 marked reviewed, remain `gameplayAuthorized: false`.** A draft is not a certified ledger or a change to the active graph registry.
- Added navigation links from the project home and Kiev setup-only page. All historical gameplay engine modules, phase/combat/movement profiles, approved SVG/PNG exports, source counter art, the common B4M CRT, and original PDF rules remain byte-identical.

## Known limits and next priority

This is an engineering source review instrument, **not** an independent visual/historical certification of all 442 sides. The source vector, geometry ledger and movement-rule tests may all be mutually consistent while preserving a mistake in the authored source; user adjudication of discrepancies is still required. No reviewer has yet approved 442 sides by comparing them against all printed source art. A reviewer pressing `Mark reviewed` does not count as independent proof. It is therefore not appropriate to activate Kiev's movement registry simply because this workbench passes.

Independently resolve the §10.8 Romanian country-border evidence (154 hexes remain unclassified in the territory tool), review and authorize the movement candidate, then test a genuine seven-turn **human-controlled** Kiev campaign through the browser. The approved Kiev setup page remains deployment-only, the production territory restriction is still mandatory and unresolved, and Kiev–Odessa still has not inherited a certified campaign. The playable game count remains **3/5**.
