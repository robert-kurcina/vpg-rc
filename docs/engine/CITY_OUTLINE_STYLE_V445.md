# Checkpoint 211 / v445 — City outline style promotion

The temporary orange dashed border style used in the Kiev Romanian-territory diagnostic has been promoted into the shared city-hex highlight renderer.

## Style applied

- Stroke color: `#ed8d30`
- Stroke opacity: `.95`
- Stroke width: `4.5`
- Dash pattern: `10 4`
- Line join/cap: `round`

## Scope

This replaces the previous yellow city hex outline on all five exported maps and in the shared browser renderer. City terrain classification, city center markers, labels, and gameplay are unchanged.
